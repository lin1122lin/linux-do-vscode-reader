# Linux.do 阅读器

在 VS Code 独立编辑器页面浏览 Linux.do，并用紧凑阅读器查看帖子。

## 功能

- 话题广场可选择独立页面、左侧栏或两者同时启用
- 独立页面支持最新、热门、搜索、分类和无限滚动
- 左侧栏支持原生话题列表、搜索、分类和持续加载
- 低干扰帖子阅读器，自动适配 VS Code 配色
- 回复按引用关系显示为楼中楼，正文支持滚动触底自动加载
- 支持手动点赞、取消点赞，以及回复话题或指定楼层
- 点击帖子图片可直接在 VS Code 内放大预览
- 一键代码伪装，可更改标签页文件名并联动隐藏侧栏
- 独立设置页，可控制标题、图片、布局和快捷按钮
- 使用独立持久化 Chrome Profile，通过真实浏览器上下文请求
- 所有站内请求都使用 Linux.do 正常的 Discourse 接口；不提供刷浏览量、绕过风控、自动或批量互动

## 首次配置

Linux.do 使用 Cloudflare 浏览器验证。首次使用：

1. 运行 **Linux.do：连接 Chrome 登录**。
2. 在弹出的专用 Chrome 窗口中登录 Linux.do，并完成 Cloudflare 验证。
3. 回到 VS Code 点击 **我已完成登录**。
4. 打开话题广场开始浏览。

插件使用自己的 Chrome Profile，不读取日常浏览器的历史、Cookie 或扩展。Profile
保存在 VS Code 的扩展全局存储目录，升级插件时保留。

插件会优先使用 VS Code 的 `http.proxy` 设置；未配置时会读取
`HTTPS_PROXY`、`HTTP_PROXY`、`ALL_PROXY` 及其小写环境变量。

## 使用

默认点击活动栏的 Linux.do 图标会打开独立话题广场。单击话题即可阅读；标题旁会显示回复数和浏览量。正文内链接会交给系统浏览器打开。

话题广场顶部提供最新、热门、搜索、分类、设置和代码伪装，滚动接近底部自动加载下一页。
在 **Linux.do：设置 → 话题广场 → 显示位置** 中可以改为左侧栏，或同时启用左侧栏和独立页面；修改后需要重载窗口。

在话题广场或阅读话题时按 `Ctrl+Alt+L` 可全局切换代码伪装，所有已打开的
Linux.do 页面会同步变化，新打开的话题也会继承当前状态。运行命令
**Linux.do：设置** 可以打开可视化配置页；快捷键可在该页面进入 VS Code
键盘快捷方式后自行修改。

Chrome 路径、浏览器登录入口、阅读布局和代码伪装选项都集中在该配置页中。

阅读页的“赞”和“回复”使用专用 Chrome 当前登录的账号。回复支持 Markdown，
默认在真正发布前显示二次确认；可在 **Linux.do 设置 → 互动** 中关闭互动按钮或
调整确认开关。站点自身的权限、频率限制、话题关闭状态和审核规则仍然生效。
